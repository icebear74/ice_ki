================================================================================
EINFACH KOPIEREN UND EINFÜGEN:
================================================================================

Für GPU (NVIDIA):
-----------------
pip install onnx onnxruntime-gpu

Für TensorRT (nur NVIDIA GPU):
-------------------------------
pip install torch2trt

Wenn torch2trt nicht funktioniert:
-----------------------------------
git clone https://github.com/NVIDIA-AI-IOT/torch2trt
cd torch2trt
python setup.py install

Für CPU (ohne GPU):
-------------------
pip install onnx onnxruntime

ODER: Verwenden Sie requirements Datei
---------------------------------------
pip install -r requirements-optimization.txt

================================================================================
FUNKTIONIERT NICHTS? KEIN PROBLEM!
================================================================================

TorchScript benötigt KEINE zusätzlichen Pakete!

Einfach direkt optimieren:
python optimize_checkpoint.py \
    --checkpoint checkpoints/model.pth \
    --output models/model_optimiert.pt \
    --format torchscript

Dann verwenden:
python run_video_inference_optimized.py \
    --model models/model_optimiert.pt \
    --input video.mkv \
    --output result.mkv

Speedup: 1.5-2x schneller (ohne zusätzliche Pakete!)
