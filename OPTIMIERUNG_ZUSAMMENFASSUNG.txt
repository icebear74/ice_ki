VERFÜGBARE OPTIMIERUNGEN
================================================================================

1. TensorRT (FP16/FP32)
   ⚡ Speedup: 3-5x schneller
   💾 VRAM: -40% weniger
   📦 Installation: pip install torch2trt
   ✅ Empfohlen für NVIDIA GPUs

2. TorchScript
   ⚡ Speedup: 1.5-2x schneller
   💾 VRAM: gleich
   📦 Installation: keine (in PyTorch eingebaut)
   ✅ Empfohlen wenn TensorRT nicht verfügbar

3. ONNX
   ⚡ Speedup: variabel
   💾 VRAM: variabel
   📦 Installation: pip install onnx onnxruntime-gpu
   ✅ Empfohlen für Portabilität

4. Pruning (NEU!)
   ⚡ Speedup: 1.2-1.5x schneller
   💾 Modell: -30% kleiner
   📦 Installation: keine (in PyTorch eingebaut)
   ✅ Kombinierbar mit anderen Optimierungen
   
   Zwei Varianten:
   - Strukturiert: Entfernt ganze Kanäle (empfohlen)
   - Unstrukturiert: Setzt Weights auf 0

SCHNELLSTART
================================================================================

Schritt 1: Installation (optional)
-----------------------------------
# Für TensorRT (beste Performance):
pip install torch2trt

# Für ONNX (optional):
pip install onnx onnxruntime-gpu

# Für Pruning: Keine Installation nötig!

Schritt 2: Modell optimieren
-----------------------------
# Option A: TensorRT FP16 (empfohlen)
python optimize_checkpoint.py \
    --checkpoint checkpoints/model.pth \
    --output models/model_optimiert.engine \
    --format tensorrt \
    --precision fp16

# Option B: Pruning (30% der Kanäle entfernen)
python optimize_checkpoint.py \
    --checkpoint checkpoints/model.pth \
    --output models/model_pruned.pth \
    --format pruned \
    --prune-amount 0.3 \
    --prune-type structured

# Option C: Maximum! (Pruning + TensorRT)
# Erst Pruning:
python optimize_checkpoint.py \
    --checkpoint checkpoints/model.pth \
    --output models/model_pruned.pth \
    --format pruned \
    --prune-amount 0.3

# Dann TensorRT auf gepruntem Modell:
python optimize_checkpoint.py \
    --checkpoint models/model_pruned.pth \
    --output models/model_final.engine \
    --format tensorrt \
    --precision fp16

Schritt 3: Video-Inferenz mit optimiertem Modell
------------------------------------------------
python run_video_inference_optimized.py \
    --model models/model_optimiert.engine \
    --input video.mkv \
    --output result.mkv

# Das Script erkennt automatisch das Format!

PRUNING - WAS IST DAS?
================================================================================

Pruning ist wie "Baumschneiden" für neuronale Netze:
- Entfernt unwichtige Verbindungen
- Macht das Modell kleiner und schneller
- Minimaler Qualitätsverlust (bei 20-40%)

Empfohlene Prune-Amounts:
- 10-20%: Kaum Qualitätsverlust
- 30-40%: Leichter Qualitätsverlust, guter Speedup (empfohlen)
- 50%+: Deutlicher Qualitätsverlust
