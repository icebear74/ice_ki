HOW IT WORKS
================================================================================

For ANY timestamp pattern (uniform or not):

1. Create frame_select_commands.txt
   -----------------------------------
   0 select 'eq(n,100)';
   0 select 'eq(n,101)';
   0 select 'eq(n,102)';
   ...

2. Run FFmpeg with sendcmd
   ------------------------
   nice -n 19 ffmpeg \
     -threads 6 \
     -discard nokey \          ← NEW: Faster seeking!
     -i video.mkv \
     -vf "sendcmd=f=commands.txt,select,..." \
     -y output_%05d.png

3. User sees clear logging
   -----------------------
   📄 Using FILE-BASED frame extraction for 20 timestamps
   Commands file: /tmp/batch_uhd_12345/frame_select_commands.txt
   🎬 Batch extracting 20 scenes...
