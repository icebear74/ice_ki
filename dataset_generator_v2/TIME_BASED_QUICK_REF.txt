CRITICAL BUG FIXED: Extracting ALL frames instead of specific ones

═══════════════════════════════════════════════════════════════════
  THE PROBLEM
═══════════════════════════════════════════════════════════════════

User reported:
  ❌ "He seems to extract EVERY frame"
  ❌ "I don't know your command line (it's not logged)"
  💡 "Use between(t,...) instead of frame numbers"

Root cause:
  -discard nokey + eq(n,FRAME) = INCOMPATIBLE!
  
  Why broken:
  1. -discard nokey skips non-keyframes during seek
  2. Frame counter (n) becomes offset/wrong
  3. eq(n,100) no longer matches frame 100
  4. Result: ALL frames extracted (35,000+ instead of 140!)

═══════════════════════════════════════════════════════════════════
  THE SOLUTION
═══════════════════════════════════════════════════════════════════

1. SWITCHED TO TIME-BASED SELECTION ✅

   Before (BROKEN):
   ----------------
   0 select 'eq(n,100)';     # Frame number
   0 select 'eq(n,101)';
   0 select 'eq(n,102)';
   ...

   After (WORKS):
   --------------
   0 select 'between(t,4.166667,4.458333)';   # Time range
   0 select 'between(t,8.333333,8.625000)';
   ...

   Calculation:
   ------------
   start_t = timestamp
   end_t = timestamp + (n_frames / fps)
   Example: 7 frames at 24fps = 0.291667 seconds

2. ADDED FFMPEG COMMAND LOGGING ✅

   Before:
   -------
   (no logging - user couldn't debug)

   After:
   ------
   FFmpeg command: nice -n 19 ffmpeg -threads 6 -discard nokey -i video.mkv ...

3. UPDATED PROGRESS MESSAGES ✅

   Now shows:
   ----------
   Batch extracting with TIME-BASED frame selection:
     Timestamps: 20
     Frames per timestamp: 7
     Total frames to extract: 140
     
   ✓ Frame validation passed: 140/140 frames extracted

═══════════════════════════════════════════════════════════════════
  WHY TIME-BASED WORKS
═══════════════════════════════════════════════════════════════════

Frame-based (eq(n,...)):
  ❌ Depends on frame counter
  ❌ Broken by -discard nokey
  ❌ Extracts all or wrong frames

Time-based (between(t,...)):
  ✅ Independent of frame counter
  ✅ Works with -discard nokey
  ✅ Extracts exact frames
